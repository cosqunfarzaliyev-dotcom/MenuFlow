## Stack

- **Next.js 16.3.0** (App Router), React, plain **`.jsx`/`.js`** — no TypeScript except `next.config.ts` (kept only for Next's config typing).
- **Supabase** (Postgres + Auth + Realtime) via `@supabase/ssr` (`createBrowserClient`, cookie-based session — required for `middleware.js` to work). Project: `MenuFlow`, `eu-central-1`, free tier.
- **No backend layer**: browser talks to Supabase directly with the anon/publishable key. RLS + `SECURITY DEFINER` RPCs + `BEFORE INSERT` triggers are the entire server-side.
- **Tailwind v4** (`@tailwindcss/postcss`, no `tailwind.config.js`) + `class-variance-authority`/`clsx`/`tailwind-merge` backing `components/ui/variants.js`.
- State: one non-persisted **Zustand** store (`lib/store.js`).
- Build: `npm run build` uses `--webpack` (not Turbopack); `npm run dev` uses Turbopack. No test framework — `scripts/verify-*.mjs` standalone assertion scripts are the closest thing to tests.
- Full command list, Next-16-specific gotchas, and the lint baseline: see `CLAUDE.md` → **Commands** / **Next 16 specifics** / **Lint baseline**.

## Architecture (one-paragraph map)

Four root surfaces gated by `middleware.js` role checks against `profiles.role`: `/menu/[restaurant]/[table]` (`CustomerApp.jsx`, unauthenticated), `/staff` (`StaffApp.jsx`), `/admin` (`AdminApp.jsx`, 2000+ lines, all tabs inline), `/superadmin` (`SuperAdminApp.jsx` + `components/superadmin/*`). Every mutation flows through `lib/store.js` → `lib/services/*.js` → Supabase, then the store re-fetches the whole collection (no local patching). Tenant resolution differs by surface: customer reads via the public `get_public_restaurant(slug)` RPC (replaced the `restaurants_public` view in `0020`); authenticated surfaces read the full `restaurants` row via `profiles.restaurant_id`. Full detail: `CLAUDE.md` → **Architecture**.
